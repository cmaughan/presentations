# Combined Chart Wide Design

## Goal

Make the combined swim, bike, and run chart twice as wide so dense activity data has more horizontal room.

## Scope

- Change only `combined_distance_over_years.png`.
- Use a `24x6` inch figure for the combined chart.
- Leave the single-sport charts at `12x6`.
- Keep the existing three-axis combined chart layout.

## Testing

Tests will cover the combined figure size and ensure the single-sport figure size remains unchanged.
